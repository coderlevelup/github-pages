# Initiative: Mars Yard

## Tags
`mars-yard`, `sapient-rocks`

## What It Is

The Mars Yard is a physical simulated Martian landscape built as part of the SAPIENT initiative. It's a hands-on space where learners can run code on rovers navigating a Mars-like terrain.

**"The Mars Yard is live! First learners have run code."**

The Mars Yard sits within the broader SAPIENT initiative (see `sapient-rocks.md`) but warrants its own tag because it's a distinct, concrete, visit-and-do activity that educators and learners can engage with directly.

## The Technology Stack

- **Physical rover** on a Martian landscape surface
- **Gazebo simulation** — open source robotics simulator allowing remote, distributed testing before running on real hardware
  - Repo: https://github.com/LoCO-AUV/loco_gazebo (shared sim infrastructure with LoCO AUV)
  - Maritime/Martian worlds: https://uuvsimulator.github.io/packages/uuv_simulator/docs/features/gazebo_worlds/
- **Turtle-bots** — abstracted Python commands for beginner learners, bridging the gap between Scratch and ROS
- ROS (Robot Operating System) for advanced control

## The Learning Pathway

The Mars Yard slots into the broader CoderLevelUp learning ladder:

```
Scratch (block coding)
  ↓
Micro:bit (physical computing)
  ↓
Pico Pathway Kit (sensors, LEDs, MicroPython)
  ↓
Turtle-bots / Mars Yard (rover control, abstracted Python)
  ↓
ROS / Gazebo (advanced robotics)
```

## Iziko Planetarium Connection

SAPIENT convenes public talks on planetary science and technology at the Iziko Planetarium and Digital Dome in Cape Town. These are entry points for public engagement — inspiring audiences before connecting them to hands-on activities like the Mars Yard.

Iziko Planetarium: https://www.iziko.org.za/museums/iziko-planetarium-and-digital-dome

## Angle for the Site
