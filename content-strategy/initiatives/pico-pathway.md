## What It Is

The Raspberry Pi Pico Pathway Kit is a hardware kit curated by CoderLevelUp and sold through [PiShop.co.za](https://www.pishop.co.za/store/raspberry-pi-pico-pathway-kit) at R199.90. It's designed to accompany the official Raspberry Pi Foundation [Introduction to Raspberry Pi Pico](https://projects.raspberrypi.org/en/pathways/pico-intro) pathway.

Model number: **CLU PicoH Kit**

### What's in the Box

- 1× Raspberry Pi Pico H (pre-soldered headers)
- 1× USB cable (USB A to micro B)
- 10× 5mm LEDs (mixed colours)
- 5× RGB Diffused LEDs
- 10× 100 Ohm resistors
- 1× Piezo transducer (passive buzzer)
- 2× Potentiometers (10K)
- 5× Tactile push buttons
- 20× Male-to-female jumper wires
- 20× Female-to-female jumper wires

### The Six Projects

| # | Project | Description |
|---|---|---|
| 1 | LED Firefly | Flash an LED in a pattern, add a switch |
| 2 | Party Popper | Light and sound display triggered by a pull |
| 3 | Beating Heart | Papercraft heart with pulsing LED and dial |
| 4 | Mood Indicator | Colour-coded mood check-in device |
| 5 | Sound Machine | Sound effects via buttons/potentiometer |
| 6 | Sensory Gadget | Fidget toy / sensory gadget |

## Angle for the Site

- Bridge between Code Club (software) and physical computing / robotics
- Affordable entry point for hardware (R199.90, available locally)
- Ties directly into DBE Coding & Robotics curriculum
- Gateway to more advanced projects: LoCO AUV learning pathway starts here (Scratch → Micro:bit → Pico → ROS)
