Introducing the Pico Pathway Kit: Physical Computing for R199.90

We’re excited to introduce the CLU PicoH Kit - a hardware starter kit curated by CoderLevelUp, available from PiShop.co.za for R199.90.

It’s designed to work alongside the official Raspberry Pi Foundation Introduction to Pico pathway - six projects, one affordable kit, and a bridge from screen-based coding into physical computing.

What’s in the Kit

Everything you need to complete all six projects:

  • 1× Raspberry Pi Pico H (with pre-soldered headers - no soldering required)
  • 1× USB cable (USB A to micro B)
  • 10× 5mm LEDs (mixed colours)
  • 5× RGB Diffused LEDs
  • 10× 100 Ohm resistors
  • 1× Piezo transducer (passive buzzer)
  • 2× Potentiometers (10K)
  • 5× Tactile push buttons
  • 20× Male-to-female jumper wires
  • 20× Female-to-female jumper wires

No breadboard required for the first projects. Components are chosen to match each Raspberry Pi Foundation project exactly.

The Six Projects

# Project What You Make
1 LED Firefly Flash an LED in a pattern, add a switch to control it
2 Party Popper Light and sound display triggered by a pull
3 Beating Heart Papercraft heart with a pulsing LED and a dial
4 Mood Indicator A colour-coded mood check-in device
5 Sound Machine Sound effects via buttons and a potentiometer
6 Sensory Gadget A fidget toy / sensory gadget

Each project builds on the last - from lighting one LED, all the way to a fully interactive gadget you’ve built yourself.

Why We Made This

Code Club is free software coding for young people. But when learners are ready to move into physical computing - connecting code to real-world electronics - the step up can feel steep, and hardware in South Africa can be expensive or hard to source.

The Pico Pathway Kit is our answer. It’s:

  • Affordable: R199.90 at PiShop - locally stocked, fast delivery
  • Standalone: everything you need in one kit, no extra shopping required
  • Teacher-ready: teachers in the Western Cape have already been trained on the pathway

Part of a Bigger Journey

The Pico Pathway Kit sits in the middle of the CoderLevelUp learning ladder:

Scratch (block coding) → Python → Pico Pathway Kit → Robotics → ROS

From here, learners can progress to more advanced robotics projects including the Mars Yard and LoCO AUV.

Get Yours

The CLU PicoH Kit is available now at PiShop.co.za for R199.90.
